# M15 — Provider connectors (native + constrained compatible)

## Responsibility

Native OpenAI Responses connector split from the generic compatibility connector (capability probes: system/multiturn/tools/schema/embeddings/stream/cancel, actual operator recorded); hardened Anthropic connector (actual response model/route, sanitized errors, structured-output/effort manifest, provider-policy record).

## Acceptance criteria

- WHEN a connector lacks a probed capability, THE SYSTEM SHALL reject the feature before execution (conformance).
- WHEN provider errors occur, THE SYSTEM SHALL keep sensitive provider bodies out of logs and record exact route/features.
