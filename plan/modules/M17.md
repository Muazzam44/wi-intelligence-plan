# M17 — Model catalogue endpoint security

## Responsibility

Authenticate the internal registry endpoint or expose a minimised public catalogue.

## Acceptance criteria

- WHEN an unauthenticated caller queries the catalogue, THE SYSTEM SHALL NOT enumerate internal providers, prices or routes (API security test).

## Verification (required evidence)

API security test (REM-019).
