# M06 — Evidence-object persistence (no raw prompts)

## Responsibility

Replace mandatory raw input/output TEXT columns with minimised metadata plus encrypted, classified evidence-object references carrying TTL, access grants, correction, deletion and legal-hold lineage; forward migration for existing rows.

## Acceptance criteria

- WHEN a new execution is persisted, THE SYSTEM SHALL store no mandatory raw input/output text fields — only classified object references and minimised metadata.
- WHEN retention, correction, deletion or hold events occur, THE SYSTEM SHALL propagate them across the evidence lineage and pass the privacy/DR test set.

## Verification (required evidence)

Migration, access, privacy and DR tests (HND-005).
